作者本人尚未进行本自动适配版的游戏内实测；当前正式单人档未启用它。作者其他当前配置正常游玩的反馈、离线Kahlua和原生解析检查，都不能代替本版的真实界面、转移和保存重进验收。日常使用建议选择上面的固定名单版。

独立普通容量升级实验，不是EX。本分支保留168项既有支持和排除规则；这不是普通发布版1.0.1的完整172项名单。启动时扫描一次脚本定义，更新本模组六条配方自己的候选ID和缓存；实际物品必须通过校验后才允许收费升级。不扫描世界、不逐帧轮询、不生成探测物品。

如需试用，仅在有恢复方案的隔离新单人测试档中启用。保留42/common目录，使用“蘇清·自动识别测试”制作分类；容器须卸下、放主物品栏、清空物品与全部液体。多人和专用服务器未验证。沿用普通版现有图像；本次只更新说明和元数据，不修改代码、配方、图片、Mod ID或版本。

[h2]English[/h2]
The author has not play-tested this automatic-adaptation version in the game, and it is not enabled in the current main single-player save. Reports of normal play with other current setups, offline Kahlua checks and native parsing do not replace acceptance of this version's actual UI, transfers and save/reload behavior. Prefer the fixed-list release above for regular play.

This is an independent ordinary-capacity experiment, not EX. It retains this branch's 168 supported IDs and exclusions, not the ordinary public 1.0.1 release's complete 172-ID list. Script definitions are scanned once at startup to update only its six recipes' candidate IDs/caches. Actual instances must pass validation before paid upgrades. No world scan, per-frame polling or discovery samples.

Only qualifying standard wearable containers are automatically accepted. Unknown high/dynamic capacity, OnCreate callbacks and position/size conversions require individual adapters; non-wearable crates are unsupported. Five capacity targets are 12/20/30/40/up to 49, with weight reduction 90/93/95/97/99%; higher existing values remain. This branch's existing costs, Tailoring levels and 50% actual-payment restoration rules are unchanged.

[b]Mutually exclusive with the ordinary fixed-list version: do not enable both.[/b] Mod ID: SuQingContainerUpgradeAuto_4221. Records are independent; SuQingContainerUpgrade_4221 records are not read or migrated. Do not directly replace an established upgraded save. Ordinary-version-specific bridges do not automatically support this namespace; do not enable both versions to satisfy a bridge requirement.

If testing, use only an isolated new single-player save with a recovery option. Preserve 42/common and use the “蘇清·自动识别测试” crafting category with the container unequipped in main inventory, empty of all items and fluids. Multiplayer/dedicated servers are untested. Existing ordinary-version images are reused. This update changes documentation/metadata only, not code, recipes, images, Mod ID or version.
