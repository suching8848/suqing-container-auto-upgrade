# 来源与素材 / Sources and assets

中文：本实验分支沿用作者普通容器升级的自制 Lua、配方、翻译和 AI 辅助图标。它有独立 Mod ID 和命名空间，不把当前普通发布版的新增名单冒充为本分支既有支持。原游戏和被适配装备由其各自作者提供；本仓库没有捆绑来源模组或游戏 stdlib/JAR。保留的是自制 mock fixture、原生反射检查和可移植打包/验证入口。个人名单、备份、安装回执及部署/回滚脚本未纳入，未擅加统一开源许可。

English: This experiment reuses the author's ordinary-container Lua, recipes, translations and AI-assisted icons. It has its own Mod ID and namespace and does not claim that the ordinary public release's newer support list is already part of this branch. The game and supported equipment belong to their authors; upstream mods and game stdlib/JAR are not bundled. Authored mock fixtures, native reflection checks and portable packaging/validation entry points are retained. Personal lists, backups, installation receipts and deployment/rollback scripts are excluded. No blanket open-source license is assigned.
